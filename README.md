# Nanoporous Nanoparticles for Drug Delivery — In Silico Meta-Analysis

Curated dataset and exploratory analysis of nanoporous / mesoporous polymeric and inorganic nanoparticles for drug delivery, derived from a systematic read of Ahmed et al. (2026).

## Attribution

This project is adapted from:

> applications of polymeric nanoparticles for drug delivery: A comprehensive
> review." *Results in Chemistry* 28 (2026) 103459.

## Repository structure

```
data/raw/           # First-pass keyword extraction (provenance — do not edit; git-ignored, regenerated from paper.txt)
data/processed/     # Manually curated dataset for analysis (tracked)
notebooks/          # Analysis scripts / Jupyter notebooks
src/                # Extraction utilities
results/figures/    # Generated plots (git-ignored; regenerated by step 3)
docs/               # Data dictionary and attribution notes
```

## Prerequisites

Install dependencies:

```bash
# From the repo root
python -m pip install -r requirements.txt
# (Windows Python launcher alternative: py -m pip install -r requirements.txt)
```

This repo targets Python 3. On some machines `python` resolves to Python 2.7; use the Python 3 executable or launcher explicitly:

```bash
# Windows (this machine)
"C:\Users\Summaiya Mirza\python.exe" -m pip install -r requirements.txt
"C:\Users\Summaiya Mirza\python.exe" -I src/extract_nanoporous.py ...
```

## How to run

```bash
# 1. Extract candidates from the review text
python -I src/extract_nanoporous.py C:\path\to\paper.txt data/raw/nanoporous_candidates.csv

# 2. Manually curate: data/raw/*.csv -> data/processed/nanoporous_curated.csv

# 3. Run exploratory analysis (regenerates results/figures/*.png)
python -I notebooks/01_nanoporous_meta_analysis.py
```

### Outputs
- `data/raw/nanoporous_candidates.csv` — first-pass keyword extraction (git-ignored; regenerated from `paper.txt`)
- `data/processed/nanoporous_curated.csv` — hand-curated dataset (tracked)
- `results/figures/material_counts.png`, `size_distribution.png` — generated plots (git-ignored; regenerated by step 3)
